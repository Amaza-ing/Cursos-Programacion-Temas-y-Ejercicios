# **Complete CSS Course from Scratch**

Welcome to the **Complete CSS Course**, a repository designed to help you learn and master CSS, the styling language that brings web page design to life. If you're a beginner, this course will guide you step by step so you can create attractive, responsive websites.

---

## 📌 **What will you learn in this course?**

🔹 How to apply styles to HTML elements.<br>
🔹 Basic principles of selectors and specificity.<br>
🔹 Using the box model to design web structures.<br>
🔹 Custom colors, backgrounds, fonts and typography.<br>
🔹 Modern layout techniques with Flexbox and Grid.<br>
🔹 Creating animations and transitions.<br>
🔹 Responsive design with media queries.<br>
🔹 Best practices for writing clean and scalable code.<br>

This course is organized into **practical modules**, with examples and exercises that will help you reinforce each concept.

---

## 📂 **Course structure**

Each topic is in a **Markdown (`.md`)** file in this repository. You can explore the topics at your own pace:

| 📚 Topic | Description |
| ------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 🎨 [Topic 1: Introduction to CSS](Temas/CSS-01-Introduccion.md) | What CSS is and how it works.                                |
| 🔗 [Topic 2: Selectors and Specificity](Temas/CSS-02-Selectores.md) | How to select and apply styles to elements.        |
| 📦 [Topic 3: The Box Model](Temas/CSS-03-Modelo-de-Caja.md) | The internal structure of elements and how to manipulate it.     |
| 🎨 [Topic 4: Units of Measurement](Temas/CSS-04-Unidades.md) | Using absolute and relative units.                     |
| 🌈 [Topic 5: Colors and Backgrounds](Temas/CSS-05-Colores-y-Background.md) | Applying custom colors, gradients and backgrounds. |
| ✍️ [Topic 6: Typography and Fonts](Temas/CSS-06-Tipografia.md) | Customizing text and using external fonts.       |
| 🗺 [Topic 7: Positioning](Temas/CSS-07-Posicionamiento.md) | Customizing text and using external fonts.       |
| 📐 [Topic 8: Flexbox](Temas/CSS-08-Flexbox.md) | Flexible layout of elements in a single dimension.        |
| 🗂️ [Topic 9: CSS Grid](Temas/CSS-09-Grid.md) | Layout in two-dimensional grids.                     |
| 👁‍🗨️ [Topic 10: Pseudo-classes and Pseudo-elements](Temas/CSS-10-Pseudoclases-y-Pseudoelementos.md) | More flexibility and control over elements.             |
| 🎞️ [Topic 11: Animations and Transitions](Temas/CSS-11-Animaciones-y-Transiciones.md) | Creating animations and dynamic effects.               |
| 📱 [Topic 12: Media Queries and Responsive Design](Temas/CSS-12-Responsivo.md) | Adapting websites to different devices.         |

📌 **You will also find solved exercises in the [Exercises](Ejercicios) folder to practice what you have learned.**

---

## 🛠️ **Prerequisites**

This course is designed for beginners, so you don't need any prior knowledge. However, it will help to have:

- Basic knowledge of HTML.
- An updated web browser (Google Chrome, Firefox, Edge, etc.).
- A code editor such as Visual Studio Code or Sublime Text.

---

## 📌 **How to use this repository**

You can follow the course directly from this repository or download it to study it on your computer.

1️⃣ **Clone the repository** to your local machine.

2️⃣ **Explore the topics** and follow the guides in each `.md` file.

3️⃣ **Do the exercises** and test your skills with practical examples.

4️⃣ **Apply what you have learned** by creating your own projects.
