# **Complete Angular Course**

Welcome to the **Complete Angular Course**! This repository is designed to guide you step by step from the basics to the most advanced features of Angular, the popular framework for developing web applications. Whether you are a complete beginner or already have some basic knowledge, this course is perfect for you.

---

## 📌 **What will you learn in this course?**

🔹 Angular fundamentals and environment setup.<br>
🔹 Creating and managing standalone components.<br>
🔹 Using directives such as `@if` and `@for` in Angular.<br>
🔹 Handling data with services and managing global state with signals.<br>
🔹 Creating reactive forms and validations.<br>
🔹 Routing and navigation in SPAs with `Router` and `RouterLink`.<br>
🔹 Consuming APIs with `HttpClient` and handling asynchronous data.<br>
🔹 Writing unit tests with Jasmine and Karma.<br>
🔹 Best practices for structuring and scaling Angular applications.

This course is divided into **practical topics**, each with examples, solved exercises and tasks to help you reinforce your knowledge.

## 🛠️ **Prerequisites**

This course is designed for beginners, so no prior experience with Angular is required, but it is a good idea to have a basic knowledge of:

- HTML
- CSS
- JavaScript and TypeScript

**Before you begin, make sure you have:**

- Node.js and npm installed ([download Node.js](https://nodejs.org/)).
- Angular CLI installed globally:
  ```bash
  npm install -g @angular/cli
  ```
- A recommended code editor (Visual Studio Code).

That said, all of this is explained step by step in the first topics.
