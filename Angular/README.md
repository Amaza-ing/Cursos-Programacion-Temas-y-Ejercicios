# **Complete Angular Course**

Welcome to the **Complete Angular Course**! This repository is designed to guide you step by step from the basics to the most advanced features of Angular, the popular framework for developing web applications. If you are a beginner or have basic knowledge, this course is perfect for you.

---

## 📌 **What will you learn in this course?**

🔹 Angular basics and environment configuration.<br>
🔹 Creation and management of standalone.<br> components
🔹 Using directives like `@if` and `@for` in Angular.<br>
🔹 Data management with services and global state management using signals.<br>
🔹 Creation of reactive forms and validations.<br>
🔹 Routing and navigation in SPA applications with `Router` and `RouterLink`.<br>
🔹 API consumption using `HttpClient` and asynchronous data handling.<br>
🔹 Performing unit testing with Jasmine and Karma.<br>
🔹 Best practices for structuring and scaling Angular applications.

This course is divided into **practical topics**, each with examples, solved exercises and tasks so that you can reinforce your knowledge.

## 🛠️ **Prerequisites**

This course is designed for beginners, so prior experience with Angular is not required, but it is advisable to have basic notions of:

-HTML
-CSS
- JavaScript and TypeScript

**Before you begin, make sure you have:**

- Node.js and npm installed ([download Node.js](https://nodejs.org/)).
- Angular CLI installed globally:
  ```bash
  npm install -g @angular/cli
  ```

- A recommended code editor (Visual Studio Code).

Although all this is explained step by step in the first topics.
