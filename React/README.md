# **Complete React Course from Scratch**

Welcome to the **Complete React Course**, a repository designed to help you learn React step by step from scratch, with a fully hands-on approach. If you already have a basic knowledge of HTML, CSS and JavaScript, this course will let you build modern, scalable and professional web applications with React.

---

## 📌 **What will you learn in this course?**

🔹 Create a React project from scratch.<br>
🔹 Understand the file structure of a React application.<br>
🔹 Create and reuse components.<br>
🔹 Apply styles in React in different ways.<br>
🔹 Handle events and state with `useState`.<br>
🔹 Render content conditionally.<br>
🔹 Work with lists and keys (`key`).<br>
🔹 Communication between components (props, lifting state up).<br>
🔹 Correct use of `className` and `htmlFor`.<br>
🔹 The component lifecycle with `useEffect`.<br>
🔹 Consuming APIs with Fetch and Axios.<br>
🔹 Controlled forms.<br>
🔹 Navigation with React Router (normal, parametric and protected routes).<br>
🔹 Global state management with Context.<br>
🔹 Optimization with `memo` and lazy loading.<br>
🔹 Testing in React.<br>
🔹 Best practices and common patterns in React.<br>

The course is organized into **progressive topics**, each one with practical exercises to reinforce the concepts.

## 🛠️ **Prerequisites**

This course is aimed at people with basic knowledge of:

- HTML
- CSS
- JavaScript (variables, functions, arrays, objects and promises)

Additionally, you will need:

- Node.js (v18 or higher recommended)
- A code editor (Visual Studio Code recommended)
