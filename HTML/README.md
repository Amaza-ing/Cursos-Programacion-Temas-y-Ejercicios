# **Complete HTML Course from Scratch**

Welcome to the **Complete HTML Course**, a repository designed to help you learn and master HTML, the fundamental markup language for building web pages. If you're a beginner, this course will guide you step by step through the structure and correct use of HTML.

---

## 📌 **What will you learn in this course?**

🔹 The basic structure of an HTML document.<br>
🔹 How to use headings, paragraphs and text formatting.<br>
🔹 Lists, links and navigation between pages.<br>
🔹 Tables, forms and user interaction.<br>
🔹 Accessibility and good practices for an inclusive web.<br>
🔹 Introduction to SEO and metadata to improve indexing.<br>
🔹 Semantic elements and why they matter for organizing content.<br>

This course is structured in **practical modules**, each with examples and exercises that will help you reinforce what you've learned.

---

| 📝 [Topic 10: Forms in HTML](Temas/HTML-10-Formularios.md)            | Creating forms and interacting with the user.             |

## 🛠️ **Prerequisites**

This course starts from scratch, so you don't need any prior knowledge. However, to get the most out of it, we recommend:

- An up-to-date web browser (Google Chrome, Firefox, Edge, etc.).
- A code editor such as Visual Studio Code or Sublime Text.

## 📌 **How to use this repository**

You can follow the course directly in this GitHub repository or download it to study on your computer.

1️⃣ **Clone the repository** to your local machine.

2️⃣ **Explore the topics** and follow the guides in each `.md` file.

3️⃣ **Do the exercises** and check your knowledge with practical examples.
