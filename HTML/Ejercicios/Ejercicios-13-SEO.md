# **Exercises - Topic 13: Metadata in HTML and basic SEO**

## **Instructions:**

Below you'll find 5 practical exercises on metadata in HTML and basic SEO.

Try to solve them before looking at the solution.

---

### **Exercise 1: Add a meta description**

Add an appropriate meta description for a web page about web development.

<details><summary>Show solution</summary>

```html
<meta
  name="description"
  content="Aprende desarrollo web con HTML, CSS y JavaScript desde cero. Recursos y tutoriales gratuitos."
/>
```

</details>

---

### **Exercise 2: Set up Open Graph for social media previews**

Write the Open Graph tags needed to improve how a blog page looks on social networks.

<details><summary>Show solution</summary>

```html
<meta property="og:title" content="10 Consejos para Mejorar tu Código HTML" />
<meta
  property="og:description"
  content="Descubre los mejores trucos y consejos para escribir código HTML más limpio y eficiente."
/>
<meta property="og:image" content="https://ejemplo.com/img/consejos-html.jpg" />
<meta property="og:url" content="https://ejemplo.com/consejos-html" />
<meta property="og:type" content="article" />
```

</details>

---

### **Exercise 3: Define a `robots` tag**

Specify a meta tag that prevents search engines from indexing the page.

<details><summary>Show solution</summary>

```html
<meta name="robots" content="noindex, nofollow" />
```

</details>

---

### **Exercise 4: Set the page title**

Write an effective `<title>` tag for an online sportswear store.

<details><summary>Show solution</summary>

```html
<title>
  Compra Ropa Deportiva | Descuentos Exclusivos en Zapatillas y Equipamiento
</title>
```

</details>

---

### **Exercise 5: Set up the viewport for mobile devices**

Add the appropriate meta tag to make a web page responsive on mobile devices.

<details><summary>Show solution</summary>

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

</details>
