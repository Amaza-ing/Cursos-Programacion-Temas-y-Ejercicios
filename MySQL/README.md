# **Complete MySQL Course from Scratch**

Welcome to the **Complete MySQL Course**, a repository designed to help you learn, step by step, how to use this powerful database management system. If you are a beginner, here you will find clear explanations, practical examples and solved exercises that will take you from the fundamentals to advanced techniques.

---

## 📌 **What will you learn in this course?**

🔹 Basic concepts of databases and MySQL.<br>
🔹 Creating and modifying tables.<br>
🔹 Using primary keys, foreign keys and constraints.<br>
🔹 Database normalization.<br>
🔹 Queries with `SELECT`, `WHERE`, `ORDER BY` and logical operators.<br>
🔹 Aggregate functions and `GROUP BY`.<br>
🔹 Table joins (`JOIN`).<br>
🔹 Inserting, updating and deleting data.<br>
🔹 Creating and using views.<br>
🔹 Indexes to optimize queries.<br>
🔹 Stored procedures and functions.<br>
🔹 Triggers and transaction management.<br>
🔹 Control structures (`IF`, `WHILE`, `REPEAT`, `LOOP`).<br>
🔹 Advanced queries with `PARTITION BY`, `WITH` and subqueries.<br>

This course is organized into **practical topics**, each with explanations and exercises to reinforce what you have learned.

---
