# **Complete Vue Course from Scratch**

Welcome to the **Complete Vue 3 Course**, a repository designed to help you learn and master Vue.js, one of the most popular frameworks for modern web development. If you have a basic knowledge of HTML, CSS and JavaScript, this course will guide you step by step through building dynamic, reactive applications with Vue 3.

---

## 📌 **What will you learn in this course?**

🔹 How to install and set up a Vue project with Vite.<br>
🔹 The basic structure of a Vue 3 component.<br>
🔹 Handling events, forms and two-way binding.<br>
🔹 Creating components and making them communicate using Props, Emits and Slots.<br>
🔹 Working with the component lifecycle.<br>
🔹 Creating and managing routes with Vue Router.<br>
🔹 Managing global state with Pinia.<br>
🔹 Making requests to an external API with `fetch` and `async/await`.<br>
🔹 Writing unit tests with Vitest.<br>
🔹 Applying dynamic styles and conditional classes.<br>
🔹 Best practices and recommended patterns in Vue 3.<br>

This course is structured into **practical topics**, each with clear explanations, examples and solved exercises to reinforce what you've learned.

## 🛠️ **Prerequisites**

This course is designed for students who already have a basic grasp of:

- HTML
- CSS
- JavaScript (functions, objects, arrays and promises)

You'll also need to have installed:

- Node.js (v18 or higher recommended).
  [Download Node.js](https://nodejs.org/).
- A code editor (Visual Studio Code recommended)

## 📌 **How to use this repository**

You can follow the course directly from this GitHub repository or download it to work on it locally.

1️⃣ **Clone the repository**.

