# **Complete Vue Course from Scratch**

Welcome to the **Complete Vue 3 Course**, a repository designed to help you learn and master Vue.js, one of the most popular frameworks for modern web development. If you have basic knowledge of HTML, CSS and JavaScript, this course will guide you step by step through creating dynamic and reactive applications with Vue 3.

---

## 📌 **What will you learn in this course?**

🔹 How to install and configure a Vue project with Vite.<br>
🔹 The basic structure of a Vue component 3.<br>
🔹 Handle events, forms and bidirectional binding.<br>
🔹 Create and communicate components using Props, Emits and Slots.<br>
🔹 Work with the Life Cycle of a component.<br>
🔹 Create and manage routes with Vue Router.<br>
🔹 Manage global state using Pinia.<br>
🔹 Make requests to an external API with `fetch` and `async/await`.<br>
🔹 Perform unit testing with Vitest.<br>
🔹 Apply dynamic styles and conditional classes.<br>
🔹 Best practices and recommended patterns in Vue 3.<br>

This course is structured into **practical topics**, each with clear explanations, examples and solved exercises to reinforce what has been learned.

## 🛠️ **Prerequisites**

This course is designed for students who already have basic notions of:

-HTML
-CSS
- JavaScript (functions, objects, arrays and promises)

You will also need to have installed:

- Node.js (v18 or higher recommended).
  [download Node.js](https://nodejs.org/).
- A code editor (Visual Studio Code recommended)
