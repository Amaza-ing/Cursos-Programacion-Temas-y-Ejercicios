# **Complete JavaScript Course from Scratch**

Welcome to the **Complete JavaScript Course**, a course designed for you to learn JavaScript from scratch and master one of the most widely used programming languages in web development. If you have little experience, this course will guide you step by step with clear explanations and practical exercises.

---

## 📌 **What will you learn in this course?**

🔹 JavaScript basics and syntax.<br>
🔹 Conditionals, loops and control flow structures.<br>
🔹 DOM manipulation to create dynamic pages.<br>
🔹 Using functions and modularizing your code.<br>
🔹 In-browser storage with `localStorage` and `sessionStorage`.<br>
🔹 API requests and data consumption with `fetch`.<br>
🔹 Asynchronous programming with promises and `async/await`.<br>
🔹 Event handling and performance optimization in JavaScript.<br>

This course is organized into **practical modules**, with examples and exercises that will help you reinforce what you've learned.

## 📂 **Course structure**

Each topic is in a **Markdown (`.md`)** file in this repository. You can explore the topics in the corresponding folder:

| 📚 Topic | Description |
| ------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 🚀 [Topic 1: Introduction to JavaScript](Temas/JavaScript-01-Introduccion.md) | What is JavaScript and how does it work?                         |
| 🔍 [Topic 2: Conditionals](Temas/JavaScript-02-Condicionales.md) | Using `if`, `else`, `switch` and logical operators.         |
| 🔄 [Topic 3: Loops](Temas/JavaScript-03-Bucles.md) | `for`, `while`, `do...while` and how to iterate over data.         |
| 🛠️ [Topic 4: Functions](Temas/JavaScript-04-Funciones.md) | Definition, types of functions and code modularization. |
| 🎭 [Topic 5: Objects](Temas/JavaScript-05-Objetos.md) | Creating, manipulating and using objects in JavaScript.      |
| 📦 [Topic 6: Arrays](Temas/JavaScript-06-Arrays.md) | Methods and operations with lists of data.                  |
| 🏗️ [Topic 7: Pass by Value and Reference](Temas/JavaScript-07-Valor-y-Referencia.md) | Differences and effects on variables, objects and arrays.       |
| 🎯 [Topic 8: Advanced Functions](Temas/JavaScript-08-Funciones-Avanzadas.md) | Closures, higher-order functions and more.                |
| ✨ [Topic 9: Advanced Operators](Temas/JavaScript-09-Operadores-Avanzados.md) | `spread`, `rest`, `optional chaining` and others.              |
| ⏳ [Topic 10: Special Functions](Temas/JavaScript-10-Funciones-Especiales.md) | `setTimeout`, `setInterval`, `debounce`, `throttle`, etc.   |
| ⚡ [Topic 11: Asynchrony and Promises](Temas/JavaScript-11-Promesas.md) | Promises, `async/await` and `fetch()`.                        |
| 🔗 [Topic 12: API Requests](Temas/JavaScript-12-Fetch-API.md) | How to consume data from APIs with JavaScript.                 |
| 🌐 [Topic 13: DOM Manipulation](Temas/JavaScript-13-DOM.md) | How to select and modify HTML elements dynamically.  |
| 💾 [Topic 14: Browser Storage](Temas/JavaScript-14-localStorage.md) | Using `localStorage` and `sessionStorage`.                   |
| 🤯 [Topic 15: JavaScript Curiosities](Temas/JavaScript-15-Curiosidades.md) | Strange behaviors and tricks in JavaScript.            |

📌 **To see all the available topics, check this repository.**

## 🛠️ **Prerequisites**

This course is designed for beginners, so you don't need any prior programming knowledge. However, it's a good idea to have:

- An up-to-date web browser (Chrome, Firefox, Edge, etc.).
- A code editor such as Visual Studio Code or Sublime Text.
- Some knowledge of [HTML](../HTML/) & [CSS](../CSS/).

## 📌 **How to use this repository**

You can follow the course directly in this GitHub repository or download it to your computer and study at your own pace.
